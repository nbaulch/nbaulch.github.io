# Economic Charts

Curated charts on the U.S. economy, built from public data: https://nbaulch.github.io/

Each chart lives in its own folder under `charts/`, with a written spec and a script that builds it from the source data. To rebuild a chart, open `nbaulch.github.io.Rproj` and run that chart's `build.R`. The site is built with Quarto from the `.qmd` files at the root.
